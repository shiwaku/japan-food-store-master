# permits/ — 食品営業許可オープンデータ（**検証用**）

> ## ⚠️ ここのデータは食料品店マスターに入っていない
>
> **食品営業許可オープンデータは検証用**であって、位置ソースではない。
> マスターに入るのは **Overture Places と OpenStreetMap の2つだけ**。
>
> 実測: `data/food_store_master.parquet` の `src` 列は **overture 97,600 / osm 5,384 の2値のみ**。
> 許可データ由来のレコードは **0件**。
>
> マスターの構築だけを追いたいなら、このディレクトリは読まなくてよい（[../master/](../master/) を見ること）。

## なぜ位置ソースに採らなかったか

| 理由 | 実証 |
|---|---|
| **施設マスタではなく「許可台帳」** | 同一施設が業種ごとに複数行に分かれる。[検証_食品営業許可データ_許可台帳としての重複構造.md](検証_食品営業許可データ_許可台帳としての重複構造.md) |
| **網羅性が足りない** | コンビニは 27,615 件＝実数（約56,000）の約半分。[検証_食品営業許可届出データ_網羅性と検索API適性.md](検証_食品営業許可届出データ_網羅性と検索API適性.md) |
| **自治体ごとに不均質** | 収集経路もジオコーディング有無も市区町村でばらつく。[整理_市区町村別_収集経路とジオコーディング.md](整理_市区町村別_収集経路とジオコーディング.md) |

対して Overture のコンビニは実数の 97%。位置の主ソースとしては比較にならない
（[../sources/検証_スーパーコンビニ網羅性_Overture_OSM_センサス.md](../sources/検証_スーパーコンビニ網羅性_Overture_OSM_センサス.md)）。

## 何に使うのか

**クロス検証の一材料**。POI が拾えていない業態・地域を炙り出す用途では今も有効で、
特に飲食店では管轄主体型の県で POI を上回る（[../sources/検証_飲食店網羅性_経済センサス突合.md](../sources/検証_飲食店網羅性_経済センサス突合.md)）。

### ⚠️ ここの「採らない」判断は**悉皆母集団としての評価**

上の表は「許可データ単独でマスターを作れるか」への答えで、**穴埋め（gap-fill）用途は別問題**。
2026-08-27 に届出区分「⑪ 百貨店、総合スーパー」で実測したところ、マスターに対応が無い純増が
4,191件あり、3県の500m圏外率を 62.2%→61.4% 動かした（比≤1 は維持）。**ATP のチェーンクロールでは
原理的に取れない地場スーパー・JA の生活センターがそのまま入っている**。
生鮮3業種（魚介類・食肉・野菜果物 販売業）でも純増 17,880件・圏外率 −2.1pt で、
**農水省公表値との相関が上がる**（r 0.448→0.460）。
**⚠ ただしこれは3県での数字**で、47県では投入後のほうが r が低い（issue #46）。
