# 検証: supermarket の「137%」を分解して分母を確定する

issue #33 の実測記録（2026-08-27）。再現: `python3 scripts/decompose_supermarket.py`。

## 0. 結論 — 137% は「過大」ではなく「別業態の混在」で、スーパー本体は**不足**している

マスターの supermarket 30,638 件は**業態が違う2系統の合成**で、分母も違う。

| | 件数 | ソース側の値（`src_cat`） | 対応する分母 | カバー率 |
|---|---:|---|---|---:|
| ① スーパー・GMS 本体 | **18,487** | Overture `supermarket` | センサス 561+581 = 23,401 | **79.0%** |
| ② 各種食料品店（小規模） | **12,151** | Overture `grocery_store`（浄化後） | センサス 589系 | **分母が手元に無い** |
| 合計（従来の「137%」） | 30,638 | | 23,401 | 130.9% |

- **①は 79.0% ＝ 約 4,900 店の不足**。「supermarket は過剰だから補完不要」という読みは誤り。
- ②は「その他の飲食料品小売業（589系）」相当。分母を出すには e-Stat `getStatsData` の appId が必要で
  リポジトリには無い（統計GIS は appId 不要だが、事業所数の表は API 側）。**分母不明のまま分子に混ぜない**。
- 買い物アクセス（500mメッシュに食料品店があるか）の指標では①②の区別は不要。
  **区別が必要なのは「カバー率」を語るときだけ**。②を落とすと3県の圏外率は逆に +2.0pt 悪化する（§3）。

### 決めたこと

1. **分母はセンサス 561+581（23,401）、分子は① のみ**。「supermarket 137%」は今後使わない。
2. **カテゴリ（`cat`）は分割しない**。指標は①②を区別しないので分割の利得が無く、
   viewer の `COUNTS` や既存の全 docs を巻き込む。代わりに**マスターに `src_cat` 列を追加**して、
   由来（Overture の category / OSM の shop）から後で分解できるようにした
   （`scripts/build_food_store_master.py`。件数は 102,984 と完全に一致、座標の総和も一致）。
3. **残る不足（約4,900）は OSM supermarket と許可データ⑪ の併用で埋める**（§2）。

## 1. 県別 — 地方の①は半分しかない

`検証_supermarket分解_都道府県別.csv`。**①が実数を下回る県は 44/47**。

| 都道府県 | ①のカバー率 | ①+② |
|---|---:|---:|
| 島根県 | **42.5%** | 81.1% |
| 長崎県 | 44.5% | 82.0% |
| 鹿児島県 | 45.3% | 94.7% |
| 鳥取県 | 45.7% | 85.8% |
| 高知県 | **46.9%** | 82.2% |
| 青森県 | 49.5% | 77.9% |
| 全国 | 79.0% | 130.9% |

検証3県のうち島根 42.5%・高知 46.9% が最下位付近にある。
**メッシュ検証で圏外率が過大に出る（比 農水省÷変種A が 0.42 と小さい）ことの、店舗側の主因はここ**
（[japan-food-access-analysis](https://github.com/shiwaku/japan-food-access-analysis)）。②を足しても 8割台に届かない県が並ぶ。

## 2. 残る不足を何で埋めるか

同じ突合条件（100m一致＋同ブランド500m一致）でマスターに対する純増を測った。

| 候補 | 総数 | 純増 | 500m判定の純増 | ライセンス |
|---|---:|---:|---:|---|
| OSM `shop=supermarket` | 20,345 | **4,576** | 852 | ODbL 1.0（**継承あり**） |
| 許可データ⑪ 総合スーパー | 15,140 | **4,191** | 871 | CC BY / 政府標準（**再配布可**） |
| ATP（チェーン公式サイト） | 10,429 | — | — | 公式14本 CC-0 / 自前38本 再配布不可 |

**両者は相補的**: 許可⑪ の純増 4,191 のうち OSM の純増と同じ店を指すものは
**1,208 件（28.8%）だけ**。許可⑪ 独自が 2,983 件ある。
単純合算の上限は 4,191 + 4,576 − 1,208 ＝ **約 7,559 店**で、①の不足 4,900 を上回る。

なお **fresh_food の補完（生鮮3業種の純増 17,880件）を先に入れる**方が指標は改善する
（農水省公表値との相関 r が 0.448→0.460。⑪ 単独は 0.445 とわずかに下がる）。
→ `docs/sources/検証_許可データ_生鮮3業種_補完効果.md`

- ATP は supermarket 46.6% で頭打ち（1社100〜300店の裾を約56社ぶんクロールしないと埋まらない）。
  **この不足を ATP で埋めるのは労力対効果が最も悪い**。
- OSM は業界実数（SM白書 23,078）の 88% を持ち Overture の 80% を上回る
  （`docs/sources/検証_スーパーコンビニ網羅性_Overture_OSM_センサス.md`）。ただし **ODbL の継承**が付く。
- 許可⑪ の効果はメッシュ検証済み（3県の500m圏外率 62.2%→61.4%、比≤1 維持。
  `docs/sources/検証_許可データ_総合スーパー_補完効果.md`）。

→ **順序は「許可⑪ を先、OSM を後」**。許可⑪ は再配布可でライセンス上の追加制約が無く、
効果も測ってある。OSM supermarket の投入は ODbL 継承の精査（`docs/master/調査_食料品店マスターのライセンス.md`）と
セットで判断する。

## 3. ②（grocery_store 由来 12,151件）をどう扱うか

- **消さない**（実測した）。②を落としたマスター（90,833件）でメッシュ検証を回すと、
  3県の500m圏外率は **62.2% → 64.2%（+2.0pt）**、比 農水省÷変種A は 0.420 → 0.407 に悪化する。
  ②12,151件の寄与（−2.0pt）は **ATP 基準への組み替え +16,108件 の −2.4pt に匹敵する**。
  買い物アクセスの目的では小規模食料品店も調達点として有効で、地方では①の穴を部分的に埋めている
  （§1 の「①+②」列で福井 102.0%・熊本 104.7% など）。
  ```
  # 検証器は japan-food-access-analysis に分離済み
  FOOD_STORES=input/tmp_master_no_grocery.parquet OUT_SUFFIX=_grocery除外 \
      python scripts/02_validate_access_difficulty.py 高知県 島根県 宮城県
  ```
- **カバー率の分子に混ぜない**。分母（589系）が取れるまでは「分母不明の別枠」として扱う。
- 2024年4月の日本標準産業分類改定で細分類「5811 食料品スーパーマーケット」が新設され、
  2026年経済センサスで初めて食品スーパーの規模が正確に取れる見込み
  （現行581は個人商店混在）。**その時点で分母を取り直す**。
