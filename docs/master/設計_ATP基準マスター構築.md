# 設計: ATP を土台にしたマスター構築

作成: 2026-08-26 ／ 実装: `scripts/build_atp_based_master.py` ／ 出力: `data/food_store_master_atp_based.parquet`
関連 issue: #30（設計）/ #28（投入前の修正）/ #29（調剤特化業態）

> **現行マスター `data/food_store_master.parquet`（102,984件）は変更していない。** 別ファイルとして並行に持つ。

## なぜ主従を逆転させるか

現行は Overture が主・OSM が補完。これを **ATP（All The Places ＋自前クロール、チェーン公式サイト由来）を土台**に
入れ替える。理由は**座標の出所**。

- ATP の座標は**その店自身が公表している位置**であって、第三者データの推定ではない。
- 実際、ATP を第三者データとして当てたことで既存データ側の測地系ズレを2件検出できた
  （マスターのデイリーヤマザキ943件が +358m/−264m、OSM のローソン11,369件が約440m。
  [../sources/検証_ATP現行データ_農水省定義適合.md](../sources/検証_ATP現行データ_農水省定義適合.md) §6）。
- 主要ブランドでは ATP と OSM が 80〜93% で100m以内に一致し、相互に裏が取れている。

ただし **ATP 単独ではマスターにならない**（supermarket 46.6% / fresh_food 0%、
3県の500m圏外率が 67.4% と現行 62.2% より悪化）。あくまで「土台＋補完」。

## 手順

```
python3 scripts/fetch_alltheplaces_jp.py data/atp     # → data/atp_food_stores_japan.parquet
python3 scripts/build_atp_geoparquet.py               # → data/atp_food_stores_japan_geo.parquet
python3 scripts/build_atp_based_master.py [半径m]     # → data/food_store_master_atp_based.parquet
```

1. **土台**: ATP 86,363件
2. **ブランド単位の置き換え**: ATP が spider を持つブランドは ATP を正とし、既存マスター側の同ブランド店を落とす。
   **ブランド名は正規化してから突合する**（`food_store_rules.normalize_brand`）。
   マスター「セブンイレブン」と ATP「セブン-イレブン」が一致しないと同じ店が二重に残る。
3. **空間デデュープ**: 残った既存マスターのうち、同カテゴリの ATP 点が **200m** 以内にあるものを落とす
   （name/brand が欠損していて 2 を素通りしたもの）
4. **補完**: 残りを ATP に足す

fresh_food は ATP がゼロなので、そのまま既存マスター（OSM 由来）が残る。

## 投入前に直した3点（#28 / #29）

### (a) 座標が系統的にずれる7チェーン

万代・ヨークベニマル・原信ナルス・イズミ・ベルク・オーケーは、**緯度は合っているのに経度だけ
−0.00215度（ほぼ一定・約200m西）**ずれていた。緯度に依存しない一定の経度オフセットなので測地系ではなく、
地図の中心座標をピン位置として拾った類の不具合。住所を100%持っていたので地理院ジオコーダで取り直した。

ヤオコーは `addr:city`「ふじみ野市」と `addr:street_address`「ふじみ野市駒林元町…」で**市名が二重**になり、
ジオコーダが番地まで解決できず市の代表点に潰れていた（204件中146件が同一座標）。

| | 修正前 | 修正後 |
|---|---|---|
| 経度の系統ズレ | −0.00215度 | ほぼ 0 |
| 同ブランド既存店までの距離 中央値 | 165〜285m | **31〜62m** |
| 同一500mメッシュ率 | 48.6〜71.7% | **76.6〜83.5%** |
| ヤオコーの座標潰れ | 146件 | 2件 |

### (b) 調剤特化業態と併設調剤の二重計上

名称に「調剤」を含む drugstore レコード 781件の内訳は、**二重計上 333件**（同一チェーンの非「調剤」店が
50m以内にある。カワチ157・ツルハ113）と**調剤専門店 448件**（スギ薬局調剤241・調剤薬局ツルハドラッグ104）。

判定には罠がある。素朴に「調剤」を含むものを落とすと**ウエルシアを巻き添えにする**。ウエルシアは
併設を注記として店舗名に付けるため（「ウエルシア 江戸川葛西店 (調剤薬局)」＝店舗本体）。
→ **括弧書きを除いた名称に「調剤」が残るもの**だけを調剤特化業態と判定する
（`food_store_rules.is_dispensing_format`）。残った重複は同一チェーン・同一ブランド50m以内で空間的に畳む。

### (c) ブランド表記ゆれ

正規化せずに突合すると同じ店が「純増」に化ける（seven_eleven の純増 3,415件のうち 1,570件＝46%が既存店）。
`normalize_brand` / `normalize_brand_sql` を `food_store_rules.py` に置き、突合前に必ず通す。

## ライセンス

出力の `redistributable` 列で行単位に判別できる。

| source_class | 件数 | 再配布 |
|---|---:|---|
| `atp_official_cc0`（ATP 公式ラン14本） | 39,358 | 可（CC-0） |
| `self_crawl`（自前クロール38本） | 47,005 | **不可**（各社規約） |
| `overture_osm` | 32,729 | 可 |

**推計・分析に使うことは制約なし**（取得も解析目的の複製も禁じられていない）。禁じられているのは
店舗データそのものの再配布なので、公開物に出すときだけ `redistributable` で絞る。
詳細は [../sources/調査_自前クロールソースの利用規約と再配布可否.md](../sources/調査_自前クロールソースの利用規約と再配布可否.md)。
