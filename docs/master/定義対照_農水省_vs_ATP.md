# 定義対照: 農水省の店舗定義 vs ATP の抽出定義

**作成**: 2026年8月28日
**目的**: 「ATP は農水省の定義に合っているのか」を、**層を分けて**厳密に対照する。
**再現**: `scripts/fetch_alltheplaces_jp.py`（`classify()`）／`scripts/build_atp_geoparquet.py`
／実データ `data/atp/*.geojson`（52ファイル・87,499地物）

> **両者は同じ層で比較できない。** 農水省は**業態の列挙**、ATP は**チェーンの名簿＋タグ変換**。
> 「率が低い＝定義が合っていない」ではなく、**母集団の性格が違う**のが本質。以下は層ごとの対照。

---

## 1. 農水省の定義（2層構造）

### ① 概念定義

> 店舗まで**直線距離500m以上** かつ **自動車利用が困難**な65歳以上高齢者

### ② 店舗レイヤの定義 ＝ 業態の列挙

2020年推計の店舗レイヤは「生鮮食料品販売店舗、食料品スーパー・コンビニ等 ＋ ドラッグストア」で、
出所は**日本スーパー名鑑・電話帳データ等**。

| # | 含む業態 | 実数統計（このリポジトリでの分母） |
|---|---|---|
| 1 | 生鮮食料品販売店舗（青果・精肉・鮮魚） | センサス582/583/584 = 33,960 |
| 2 | 食料品スーパー・**各種食料品小売業** | センサス581 = 22,378 |
| 3 | 百貨店・総合スーパー（GMS） | センサス561 = 1,023 |
| 4 | コンビニエンスストア | 商業動態 = 56,352 |
| 5 | ドラッグストア（**2020年推計から追加**） | 商業動態 = 17,622 |
| — | **調剤薬局は含まない** | — |

**この定義は業態の列挙であって、個店の食品取扱を審査していない。**
「ドラッグストアは食品を扱う」は業態に対する一般化で、店ごとの監査ではない。
2020年からドラッグストアが追加されたため 2015年以前とは非連続。

### ③ 操作化

農水省の「500m以上」は**同一500mメッシュ内の店舗存否**として実装されている（直線500m円ではない）。
実距離500m版・9近傍メッシュ版は公表値との比が1を超えて論理破綻する。
→ 検証は [japan-food-access-analysis](https://github.com/shiwaku/japan-food-access-analysis)。

## 2. ATP の定義（実装で確定している2段）

### (a) 母集団 ＝ **列挙された52本の名簿**

ルールではない。「チェーン公式サイトのストアロケータを回した spider が52本ある」という
事実がそのまま母集団。ATP 公式ラン14本（CC-0）＋自前クロール38本（再配布不可）。

### (b) 分類 ＝ `classify()`（OSM互換タグ → 4カテゴリ）

| 入力タグ | → cat | 備考 |
|---|---|---|
| `shop=supermarket` | supermarket | |
| `shop=wholesale` | supermarket | **リポジトリ側の判断**。全件コストコ（37件） |
| `shop=convenience` | convenience | |
| `shop=chemist` | drugstore | |
| `shop=greengrocer` / `butcher` / `seafood` / `fishmonger` | fresh_food | **写像は用意ずみ**（実データが無いだけ） |
| `amenity=pharmacy` かつ **brand あり** | drugstore | 併設調剤の自社店舗を取りこぼさないため |
| `amenity=pharmacy` かつ brand なし | **落とす** | otsuka_jp の調剤専業・提携薬局が丸ごと入るのを防ぐ |
| 上記以外（`shop=department_store` 含む） | 落とす | |

### (c) 実測した漏斗（2026-08-28 に `data/atp/*.geojson` を通した結果）

```
生データ計                              87,499
  − Point でない                            83
  − classify() 対象外                      394   pharmacy(brand無) 259 / cosmetics 59 /
                                                 kiosk 50 / ice_cream 7 /
                                                 department_store 5 / deli 4 …
  − 日本の外                                 0
  − 調剤専業として除外                      96
採用                                    86,926
  − 同一チェーン・同一ブランド 50m 重複     563
現在の実体（atp_food_stores_japan_geo）  86,363
```

タグ経路は `shop` タグ 85,548 ／ `amenity=pharmacy`（brand付き）1,557。
元タグの内訳は `convenience` 57,052 ／ `chemist` 18,039 ／ `supermarket` 10,419 ／
`pharmacy`(brand付) 1,557 ／ `wholesale` 37 ／ `seafood` 1。
座標は10チェーン1,750件が GSI で取り直し済み（残り 84,613件は spider の公表座標そのまま）。

## 3. 対照 — どこが一致し、どこがずれるか

| 農水省の要素 | ATP の cat | 件数 | 実数統計 | 率 | **定義レベルのズレ** |
|---|---|---:|---:|---:|---|
| 1 生鮮食料品販売店舗 | fresh_food | **1** | 33,960 | 0.0% | **タグ側は4種用意ずみ**。ズレは定義ではなく**母集団**。実データは `shop=seafood` 1件（maruetsu_jp に紛れた鮮魚専門店） |
| 2 食料品スーパー・各種食料品 | supermarket | 10,429 | 22,378 | 46.6% | **「各種食料品店」＝個人経営のよろず屋が原理的に入らない**。加えて `wholesale`（コストコ）を寄せているが、農水省の列挙に会員制卸は無い |
| 3 百貨店・総合スーパー | **対応 cat なし** | — | 1,023 | — | `shop=department_store` は `classify()` が落とす（5件）。GMS は spider が `shop=supermarket` で出すので **2 に包含**（マスター設計の方針と一致） |
| 4 コンビニ | convenience | 56,910 | 56,352 | 100.9% | **ズレほぼ無し**。業態の外縁が明確で、ほぼ完全にチェーン化している |
| 5 ドラッグストア | drugstore | 19,023 | 17,622 | 107.9% | 業態レベルでは一致。**個店の食品取扱は両者とも審査しない** |
| — 調剤薬局（除外側） | 除外 | −96 ＋ −259 | — | — | 農水省は業態で「含まない」と言うだけ。ATP は **brand の有無 ＋ 名称判定**の2本で操作化 |

件数は `data/atp_food_stores_japan_geo.parquet`（86,363件）。率の分母は
`docs/master/検証_マスターPhase1_都道府県別.csv` の `実数統計` 列。
県別は [../sources/検証_ATP単独_実数統計突合_都道府県別.csv](../sources/検証_ATP単独_実数統計突合_都道府県別.csv)。

### 一致している点

- **除外の考え方**。農水省「調剤薬局を含まない」＝ ATP の brand無し pharmacy 除外＋調剤専業の名称判定。
  どちらも**業態で切っていて個店を審査しない**。
- **GMS を独立カテゴリにしない**方針。農水省側も名鑑ベースでスーパーと連続、ATP も spider が
  タグで区別しない。

### 構造的にずれている点

**ATP の分類（b）は農水省の業態列挙を素直に写しているが、母集団（a）が違う。**

| | 農水省 | ATP |
|---|---|---|
| 母集団 | 名鑑＋電話帳＝**業態の悉皆**（個人経営を含む） | **チェーンの名簿**（52本） |
| 定義の性格 | 業態の列挙 | タグ→cat の写像 |

この結果、**カバー率はチェーン化率の関数**になる:

```
convenience 100.9%  ←  ほぼ完全チェーン化
drugstore   107.9%  ←  寡占（上位15チェーンでほぼ全部）
supermarket  46.6%  ←  地場スーパー・生協が多い
fresh_food    0.0%  ←  個人経営が大半
```

**この順序はカテゴリの重要度ではなく、業態のチェーン化率そのもの。**
だから ATP のカバー率が低いカテゴリは spider を足せば埋まるわけではない
（supermarket は1社100〜300店の裾を約56社ぶん足さないと届かない）し、
**fresh_food は原理的に埋まらない**。ATP を「土台」と呼び「マスターではない」と言っているのはここに由来する。

### 操作化（③）のレベル

| | 農水省 | ATP |
|---|---|---|
| 単位 | 500mメッシュ内の存否（二値） | 点（店の公表座標） |
| 施設 vs 台帳 | 名鑑＝施設単位 | spider ごとに併設調剤が別レコードで出るため **50m重複を563件畳んでいる**（農水省側に対応物なし） |
| 座標精度 | 名鑑・電話帳のジオコーディング（精度不明） | 公表座標。10チェーン1,750件は GSI で取り直し |

## 4. 帰結: 個店単位の「食品取扱の仕分け」は定義に無い

農水省の②は**業態の列挙**で、ドラッグストアを業態として丸ごと含める。個店の食品取扱を
判定する条項は無い。ATP 側の実装もそれに揃っていて、切っているのは
「ドラッグストア／調剤薬局」の業態境界だけ。

**したがって個店単位の食品取扱の仕分けは農水省の定義に存在しない要件**で、やれば定義から
離れる方向に動く。実装済みの調剤専業除外（96件＋brand無し259件）で定義上は充足している。

許可データでこの仕分けを試みても**できない**（欠測がチェーン単位で全滅する。CLAUDE.md の
落とし穴「許可データの『無い』は業態の証拠にならない」）。陽性方向だけなら ATP の
ドラッグストア 19,023件のうち約半分（9,623件）は確証が付くが、残り半分は
「扱っている証拠が無い」だけで「扱っていない」ではないので除外できず、500mメッシュ指標は1件も動かない。
