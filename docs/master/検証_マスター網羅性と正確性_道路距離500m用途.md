# 検証：食料品店マスターは「125mメッシュ×道路距離500m」で全国評価するのに耐えるか

> 実施日: 2026-07-26（2026-07-31 に調剤専業の除去を反映）／ 対象: 食料品店マスター Phase 1（102,984店・全国）
> 想定用途: **125mメッシュ重心から道路距離を算出し、食料品店まで500m圏内かどうかを判定**（全国）
> 観点: **網羅性**（店が足りているか）と **正確性**（載っている店が正しいか）

---

## 0. この用途で何が効くか

判定が「最近隣の1店までの距離が500mを超えるか」という**二値・距離閾値**なので、件数カバー率とは
効き方が違う。

- **過剰（同じ地域に店が多い）は無害**。すでに圏内の地点に店を足しても判定は変わらない。
- **欠落は、その店が「その地点で唯一の店」だったときだけ効く**。効いたときは、その125mメッシュの
  住民全員が圏外に振り替わる。
- したがって重要なのは **「単独店（周囲に他の店が無い店）」がどれだけあるか** と、
  **欠落がその単独店に当たる確率**。

→ 以下、網羅性は「不足数 × 単独店率」で影響を見積もり、正確性は「偽陽性（実在しない/食品を扱わない店）」と
   「位置ズレ」を実測する。

---

## 1. 網羅性

### 1.1 カテゴリ別 全国カバー率

| cat | マスター | 実数統計 | カバー率 | 不足 |
|---|---|---|---|---|
| convenience | 54,792 | 56,352 | **97%** | 1,560 |
| supermarket | 30,638 | 22,378 | 137%（広義） | （過剰） |
| drugstore | 7,484 | 17,622 | **42%** | 10,138 |
| fresh_food | 10,070 | 33,960 | **30%** | 23,890 |

supermarket の137%は誤りではなく「広義」（Overture `grocery_store` が各種食料品店を含むため）。
ただし**県単位では10県が実数を下回る**（下記1.3）。

> ⚠️ **2026-08-27 更新（issue #33）**: この 137% は分解した。Overture `supermarket` 由来 18,487 件だけを
> センサス 561+581（23,401）で割ると **79.0% ＝ 約4,900店の不足**で、`grocery_store` 由来 12,151 件は
> 589系（分母が手元に無い）。**「supermarket は過剰だから補完不要」は誤り**。
> → [検証_supermarket分解と分母の確定.md](検証_supermarket分解と分母の確定.md)

### 1.2 単独店率（この用途での感度）

500m**直線**距離以内に他の食料品店が1軒も無い店舗の割合。
**道路距離は直線距離以上**になるので、道路距離ベースでは単独店はこれより増える＝**下限値**。

| cat | 総数 | 単独店 | 単独率 |
|---|---|---|---|
| convenience | 54,792 | 9,062 | **16.5%** |
| supermarket | 30,638 | 3,493 | 11.4% |
| fresh_food | 10,070 | 1,060 | 10.5% |
| drugstore | 7,484 | 350 | 4.7% |

### 1.3 欠落の影響見積もり

不足数 × 単独店率 ＝「実際は店があるのに、マスターでは圏外と判定される地点」の概数:

| cat | 不足 | 単独率 | 影響地点（概数） |
|---|---|---|---|
| fresh_food | 23,890 | 10.5% | **約 2,515** |
| drugstore | 10,138 | 4.7% | 約 474 |
| convenience | 1,560 | 16.5% | 約 258 |
| **計** | | | **約 3,247（下限）** |

これは下限である。理由は2つ:

1. **道路距離は直線距離以上**なので単独率は上振れする。
2. **欠落は地方に偏る**（Overture の地方取りこぼし）。地方の単独率は全国平均より高い:

   鳥取 28.5% / 佐賀 27.7% / 長野 27.1% / 茨城 26.8% / 鹿児島 26.2% /
   島根 25.0% / 徳島 24.5% / 宮崎 24.4% / 熊本 23.5% / 栃木 23.4%

## 2. 正確性

### 2.1 位置精度（125mメッシュ判定に直接効く）

同一コンビニの Overture 座標と OSM 座標のズレを実測（200m以内で最近隣対応づけ、34,493組）:

| 統計 | ズレ |
|---|---|
| 中央値 | **14.7 m** |
| p90 | 147.3 m |
| p99 | 227.6 m |
| 最大 | 278.1 m |

> 注: 200m以内でペアリングしているため裾は切断されており、また片方にしか無い店が近くの別店と
> 誤対応して裾を膨らませる。**中央値は頑健、p90/p99 は上振れ**と読むべき。

**評価**: 中央値15mは500m閾値に対して無害。ただし **p90 の147mは125mメッシュのセル対角（約177m）と
同オーダー**なので、500m境界付近のメッシュでは判定が反転しうる。境界ケースの感度分析（閾値450m/550mで
結果がどれだけ動くか）を推奨する。

### 2.2 偽陽性（実在しない／食品を扱わない店）

圏内と誤判定させる方向の誤差。

| 種別 | 件数 | 対マスター |
|---|---|---|
| 調剤専業の疑い（`薬局`/`調剤` を含み、ドラッグストアチェーンにも該当しない） | **246**（2026-07-31 に除去済み） | 0.2% |
| その他ノイズ名称（カフェ/食堂/雑貨/100円 等）| convenience 145・supermarket 48・fresh_food 9・drugstore 2 | 0.2% |
| **閉店店舗** | **定量不能** | — |

- `薬局`/`調剤` を含むレコードは 663 件（drugstore 648・convenience 15）。当初は「大手19チェーンに
  一致しない **317件**」を調剤専業と見積もったが、**この見積もりは過大だった**。317件を実際に目視すると
  **食品を扱う地方ドラッグストアが混ざっていた**（レデイ薬局14・ヤックスドラッグ14・ウォンツ13・
  ドラッグセイムス8・ウェルネス3・杏林堂2・セガミ2・大賀薬局2・セキ薬局2 ほか）。
  これらを落とすと圏外を過大判定する方向の誤差になる。
- Overture 側に手がかりは無い（`category_alt` に `pharmacy` は**1件も無い**）ので、名称で判定するしかない。
  地方チェーンを名寄せリストに加え、屋号に `ドラッグ`/`くすり`/`薬品` 等を含むものも救う条件にして、
  最終的に **246件**（drugstore 245・convenience 1）を除去した。判定は
  `scripts/food_store_rules.py`（構築・検証で共有）。設計書7章「調剤薬局は除外」に準拠。
- **閉店店舗は Overture からは原理的に除外できない**（確定）。`operating_status` は deduped 版・full 版とも
  **日本の234,077件すべて NULL**。`設計_食料品店マスター構築.md` 10-5 は「full版や更新版で対応」と
  していたが、full 版でも空なので**この手は無い**。閉店の除外には別ソースが必要で、
  現状は**定量できない偽陽性リスク**として制約に明示するしかない。
- **`confidence` は使えるのに未使用**。deduped 版に `confidence`（Overture の信頼度）があるが、
  `scripts/build_food_store_master.py` は参照していない。マスター対象カテゴリでの分布:

  | category | 件数 | 中央値 | confidence<0.5 | <0.3 |
  |---|---|---|---|---|
  | convenience_store | 54,987 | 0.800 | 1,259 | 517 |
  | grocery_store | 20,608 | 0.770 | 1,876 | 258 |
  | supermarket | 18,521 | 0.878 | 687 | 137 |
  | butcher_shop | 4,261 | 0.887 | 146 | 23 |
  | drugstore | 7,735 | 0.770 | 0 | 0 |
  | seafood_market | 445 | 0.770 | 0 | 0 |
  | **計** | | | **3,968** | **935** |

  → 閉店を直接は判定できないが、**低信頼レコードを落とす偽陽性フィルタとして即使える**。

### 2.3 重複（同一店舗が複数レコード）

名称が一致し50m以内にある組: **457件（0.4%）** — supermarket 298 / convenience 86 / fresh_food 73。

**最近隣距離の判定には無害**（同じ場所に2レコードあっても距離は変わらない）。件数集計にのみ影響する。

### 2.4 座標品質（破壊的な問題は無い）

| 項目 | 件数 |
|---|---|
| ジオコーディング代表点への集積 | **なし**（最多でも1点5件） |
| 座標が小数3桁以下（≒100m格子に丸め） | 3 |
| 完全同一座標に重なる組 | 244 |
| 名称 NULL/空 | 495（0.5%） |

食品営業許可データで起きた「level1 の8万件が県庁に集積」のような**アクセス解析を壊す要因は無い**。

## 3. 判定

| カテゴリ | 全国評価に使えるか |
|---|---|
| convenience | ✅ 使える（97%） |
| supermarket | ⚠️ 都市部は使える。**青森・島根・高知・長崎・鳥取の5県は明確な穴**（80〜90%） |
| drugstore | ❌ 42%。対象業種に含めるなら圏外を過大判定する |
| fresh_food | ❌ 30%。同上。**影響は最大（約2,500地点）** |

**総合**: 全国スクリーニング（相対的にどこが厳しいか）には使える。ただし
**地方で系統的に圏外を過大判定する**。「実際は店があるのに圏外と判定される地点」が**3,200以上**あり、
道路距離ベースかつ地方偏りを考慮すると実際はさらに大きい。

絶対値（◯◯市に何人が圏外）を出す用途には、少なくとも fresh_food の補完が前提になる。

## 4. 対処の優先順位（効果／手間 順）

1. ~~**調剤専業317件の除去**~~ → **2026-07-31 完了（246件を除去）**。317件のうち約70件は食品を扱う
   地方ドラッグストアだったため、名寄せリストを拡張したうえで除去した（2.2 参照）。
   drugstore は 7,729 → 7,484 になり、カバー率は 44% → **42%**（不足 10,138）に下がった。
2. **fresh_food の補完** — 最大の穴（不足23,890・影響約2,500地点）。
   OSM の greengrocer/butcher/seafood は計6,890件しかなく、センサス582/583/584 との差を埋める
   新ソースの探索が必要（＝重い）。
3. **地方 supermarket の穴埋め** — 5県（青森・島根・高知・長崎・鳥取）。OSM supermarket の
   独自分を該当県に限って追加する案が既に検討済み（`../archive/Phase1検証まとめと次の一手.md`）。
4. **`confidence` を偽陽性フィルタとして導入** — 未使用。`confidence<0.5` で3,968件、`<0.3` で935件。
   閾値は圏内判定の変化量を見て決める。閉店の直接除外は Overture では不可能（`operating_status` 全NULL）
   なので、**「閉店を除外できていない」は制約として明示する**しかない。
5. **境界ケースの感度分析** — 位置精度 p90 147m が125mメッシュ判定に効くため、
   閾値450m/550mで結果がどれだけ動くかを見る。
