# 検証: All The Places（ATP）を第3の位置ソースに採るか

検証日: 2026-08-09 ／ 対象ラン: ATP `2026-08-01-13-32-15`（4,898 spider・44,670,780 件）
再現: `scripts/fetch_alltheplaces_jp.py` → `scripts/compare_atp_with_master.py`
付随データ: [検証_AllThePlaces_都道府県別.csv](検証_AllThePlaces_都道府県別.csv)

> **この検証時点でマスターは変更していない。** `data/food_store_master.parquet` は
> 従来どおり overture 97,600 / osm 5,384 の 102,984 件。以下はすべて「入れたらどうなるか」の試算。

## 結論

| カテゴリ | 判定 | 理由 |
|---|---|---|
| **drugstore** | **採用を推奨** | 純増 4,853。カバー率 42.5% → 70.0% と実数（商業動態 17,622）に近づき、超過しない |
| **convenience** | **保留**（そのままでは入れられない） | 純増 4,556 を入れると 97.2% → **105.3% と実数超過**。ファミマ欠損は実在するので、先にマスター側の偽陽性を精査すべき |
| **supermarket** | 見送り | 純増 234 と小さく、現行が既に 136.9%（広義）で超過側 |
| **fresh_food** | **効かない** | ATP はチェーン公式サイトのスクレイパー集で、個人経営の青果・鮮魚・精肉店は原理的に載らない。純増 **0** |

ライセンス面では ATP 出力は **CC-0**（コードは MIT）で、公開の律速である OSM の ODbL 継承を
持ち込まない。ただし今回の純増はいずれも OSM 由来物を置き換えるものではないので、
**ODbL 律速の解消にはならない**（[master/調査_食料品店マスターのライセンス.md](../master/調査_食料品店マスターのライセンス.md)）。

## 1. ソースの素性

- 公式サイトのストアロケータを Scrapy で巡回し、**OSM 互換タグ**（`shop=supermarket`,
  `addr:country=JP`, `brand`, `branch`, `opening_hours` 等）付きの GeoJSON を週次公開する。
- 出力は **CC-0**。個別 spider は `output/<spider>.geojson` で単体取得もできる。
- 日本の食料品店を含む spider は **14 本**、抽出 **39,590 件**（都道府県ポリゴン内。生 39,774 件）。

| cat | 件数 | 内訳（spider） |
|---|---|---|
| convenience | 30,328 | familymart 16,182 / lawson 14,101 / aeon_hokkaido 45 |
| drugstore | 7,886 | matsukiyo 3,664 / tsuruha 2,897 / seims 1,128 / tomods 197 |
| supermarket | 1,376 | life 323 / valor 249 / seijoishii 229 / aeon_hokkaido 182 / heiwado 170 / beisia 140 / itoyokado 91 / costco 37 |
| fresh_food | 0 | — |

**存在しない spider**: セブン-イレブン日本法人、イオン本体、マックスバリュ、ヤオコー、業務スーパー、
ウエルシア、スギ、サンドラッグ、コスモス。`ministop_jp` は存在するが**このランでは出力 0 件**
（spider の故障。件数が前ランと大きく違うときは ATP 側の失敗を疑うこと）。

### 落とし穴: `amenity=pharmacy` の扱い

ドラッグストア系 spider は**調剤併設の自社店舗を `shop=chemist` ではなく `amenity=pharmacy` で出す**。
これを落とすと ココカラファイン 489・マツモトキヨシ 393 など約 1,290 件を取りこぼす。

一方で素通しすると **`otsuka_jp`（大塚製薬の薬局・医療機関検索、24,906 件）が丸ごと入る**。
中身は「くどう薬局」等の調剤専業と「調剤薬局ツルハドラッグ赤平店（保険調剤窓口）」のような
調剤窓口で、いずれも食料品店ではない。

両者を分けるのは **brand の有無**。チェーン自社店舗には brand が入り、`otsuka_jp` は 20,764 件
すべて brand が空、`tomods_jp` / `seims_jp` の提携調剤薬局（「あいあい薬局」等）も空。
よって **brand 付きの `amenity=pharmacy` のみ drugstore として採る**。
なお `shop=wholesale` は日本では全件コストコ（37 件）。

## 2. 重複判定は「同カテゴリ100m」だけでは足りない

ATP と Overture で同一店舗の座標が数百m離れることがあり、**同じファミリーマートが
「純増」に化ける**。半径を振ると純増が崩れるのがその証拠:

| cat | 100m | 200m | 500m |
|---|---|---|---|
| convenience | 7,301 | 5,168 | 2,139 |
| supermarket | 373 | 279 | 100 |
| drugstore | 5,288 | 4,712 | 3,558 |

コンビニ・スーパーは半径を広げると急減する＝**座標ズレ**。drugstore だけ減り方が緩く、
これは実在の穴（マスター 7,484 に対し商業動態 17,622・JACDS 約 21,000）。

そこで判定を **「同カテゴリ 100m 以内」または「同ブランド 500m 以内」** の2段構えにした。
ブランド一致は **brand 列同士を先に見る**こと。ATP の brand `"FamilyMart"` は Overture の
name「ファミリーマート」と一致しないが、**マスター側にも brand 列があり `"FamilyMart"` が入っている**。
name だけで突合していたため、当初はファミマの純増を 3,886 件も過大評価していた。

## 3. 座標精度（spider 別）

同ブランドの既存マスター店舗までの距離。距離閾値 500m で判定するマスターなので、
ジオコーディング品質の悪い spider は入れてはいけない。

| spider | ATP | 純増 | 対応 | 中央値 | p90 |
|---|---|---|---|---|---|
| familymart_jp | 16,182 | 3,870 | 12,291 | **1m** | 382m |
| lawson_jp | 14,101 | 685 | 13,542 | **1m** | 134m |
| matsukiyo_jp | 3,664 | 1,978 | 1,563 | 22m | 291m |
| tsuruhadrug | 2,897 | 1,972 | 853 | 18m | 381m |
| seims_jp | 1,128 | 799 | 210 | 11m | 61m |
| tomods_jp | 197 | 104 | 51 | 59m | 212m |
| costco_jp | 37 | 31 | 4 | 63m | 105m |
| **aeon_hokkaido_jp** | 182 | 24 | 157 | **404m** | 429m |

`aeon_hokkaido_jp` だけ桁違いに悪く、住所ジオコーディング品質。**投入対象から外すこと**。
他は中央値 1〜63m で、Overture と同等かそれ以上。座標の完全重複は 34 件のみでクリーン。

## 4. 都道府県別カバー率（実数統計が分母）

全国計。県別は [検証_AllThePlaces_都道府県別.csv](検証_AllThePlaces_都道府県別.csv)。

| cat | 現行 | 純増 | 投入後 | 実数統計 | カバー率 |
|---|---|---|---|---|---|
| convenience | 54,792 | 4,556 | 59,348 | 56,352 | 97.2% → **105.3%** |
| supermarket | 30,638 | 234 | 30,872 | 22,378 | 136.9% → 138.0%（広義） |
| drugstore | 7,484 | 4,853 | 12,337 | 17,622 | 42.5% → **70.0%** |
| fresh_food | 10,070 | 0 | 10,070 | 33,960 | 29.7% → 29.7% |

### convenience が実数を超えるのはなぜか

マスターのコンビニをチェーン別に数えると、**ファミマだけが実数から大きく欠けている**:

| チェーン | マスター | 実数 |
|---|---|---|
| セブン-イレブン | 20,437 | 約 21,000 |
| ローソン | 12,189 | 14,101（ATP 実測） |
| **ファミリーマート** | **9,101** | **16,182（ATP 実測）** |
| その他 | 13,065 | 約 5,000 |

ファミマの欠損 約 7,000 は実在する。にもかかわらず全国計が 97.2% で収まっているのは、
**「その他」13,065 が実数（約 5,000）に対して過大**だから。つまりマスターのコンビニには
偽陽性が相当数あり、それがファミマ欠損を打ち消して総数を「正しく見せている」。

ATP のファミマを足すだけだと、この偽陽性を残したまま総数だけが実数を超える。
島根 1.145 → 1.245、鳥取 1.150 → 1.232 のように、**現行ですでに超過している県で悪化する**。

→ **convenience は「足す」前に「引く」検証が要る**。順序は
①マスターの無名・その他コンビニの偽陽性を精査 → ②ATP のファミマで補完。

## 5. アクセス困難人口での効果（試算）

fit-for-purpose の本命検証器（[master/検証_アクセス困難人口_メッシュ単位.md](../master/検証_アクセス困難人口_メッシュ単位.md)）で、
3県88市区町村を投入前後で比較した。**この試算のあとマスターは投入前の状態に戻してある。**

| 指標 | 投入前 | 投入後（約9,800件追加） |
|---|---|---|
| 変種A 500m圏外人口（65歳以上） | 685,951（62.2%） | **670,207（60.8%）** |
| 変種C 500m圏外人口 | 453,617（41.2%） | 441,631（40.1%） |
| 比 農水省÷変種A | 0.420 | **0.429** |
| 全市区町村で比 ≤ 1 | 満たす | 満たす（max 0.795） |

穴が 15,744 人分（−1.4pt）埋まり、比は 1 に近づく方向へ動いた。論理的な不整合（比 > 1）も出ない。
効果はあるが、**係数 0.42 の大半は依然として自動車利用困難率に由来する**という判断は変わらない。

> 追加件数が検証器の 9,643 件と一致しないのは、構築側の重複判定が `ST_DWithin` の
> **度数円**（緯度100m・経度122m相当の楕円）で、検証器のメートル距離と微妙に違うため。
> 構築側は都道府県外の点も先に落としている。

## 6. 副産物: 閉店の検出（次の一手 4）

ATP が spider を持つブランドかつ**同一都道府県**に限って、マスターにあって ATP に無い店を数えた
（都道府県でスコープを切らないと、北海道しか持たない `aeon_hokkaido_jp` に対して全国のイオンが
全件「消滅」に見えてしまう）。

| ブランド | マスター | ATP に無い |
|---|---|---|
| ココカラファイン | 502 | 181（36.1%） |
| セイムス | 277 | 118（42.6%） |
| マツモトキヨシ | 683 | 91（13.3%） |
| ライフ | 405 | 88（21.7%） |
| FamilyMart | 9,071 | 35（0.4%） |
| LAWSON | 11,429 | 22（0.2%） |

コンビニ2社が 0.2〜0.4% とほぼ一致するのは、両者が独立に正しいことの相互裏付けになる。
一方ドラッグストアの 13〜43% は、閉店・改称・ATP の取りこぼしが混在していて切り分けできていない。
**そのまま削除に使ってはいけない**が、閉店候補の絞り込みには使える。

## 7. 再現手順

```bash
# ① ATP の週次ランから日本の食料品店を抽出（zip 約2.75GB を data/atp/ にキャッシュ）
python3 scripts/fetch_alltheplaces_jp.py
#    既に zip があるなら渡せばダウンロードを省ける
python3 scripts/fetch_alltheplaces_jp.py path/to/output.zip

# ② マスターと突合（マスターは書き換えない）
python3 scripts/compare_atp_with_master.py          # 既定 100m
python3 scripts/compare_atp_with_master.py 500      # 半径を振って座標ズレを切り分ける
```

`RUN` 定数（`fetch_alltheplaces_jp.py`）はランの日時。更新するときは
<https://data.alltheplaces.xyz/runs/latest/info_embed.html> で最新のランIDを確認する。
