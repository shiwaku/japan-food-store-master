# 検証: Japan Food Facilities 単独で店舗レイヤを作れるか（2026-09-21）

**結論: 作れない。** チェーン名分類で最善を尽くしても、47県・地方部の相関 r が
**0.2472 → 0.2144 に下がる**。地方部の圏外率は 56.3% → 66.9% に跳ね、
**約10ポイント分の店舗を取りこぼす**。

ただし**県によっては現行マスタより店舗が多い**（富山・高知・山梨・石川・愛媛）。
単独での置き換えは無理でも、**県を選んだ補完には材料がある**（後述の注意つき）。

## 0. このソースは既にこのリポジトリが使っている

[gl20percentclub/japan-food-facilities](https://github.com/gl20percentclub/japan-food-facilities)
（以下 JFF）は、自治体と厚労省 i2fas が公開する食品営業許可・届出を全国共通形式に統合した
オープンデータ。**`data/facilities-all.csv` がまさにこれ**で、⑪ 総合スーパーの純増 3,157件は
ここから `atp_super` に投入済み（`検証_許可データ_総合スーパー_補完効果.md`）。

つまり「JFF を使えるか」は**新規ソースの検討ではなく、使う範囲を広げられるかの検討**である。
本稿は「⑪ の穴埋め」ではなく「**このソース単独で店舗レイヤを組めるか**」を測る。

| | 行数 | 時点 |
|---|---:|---|
| `data/facilities-all.csv`（リポジトリ内） | 1,363,729 | 2026-08-26 |
| 本稿で使った再取得分 | 1,325,708 | 2026-09-14 |

再取得のほうが 38,021 行**少ない**。JFF 側が座標の品質フィルタと同一施設の座標統一を
入れたためとみられる。本稿は新しい方で測った。

## 1. 業種コードで cat を振ってはいけない

届出の区分は業態と一対一に対応しない。実測（2026-09-21）:

| 測り方 | 大手コンビニ3社の網羅率 |
|---|---:|
| `⑩ コンビニエンスストア` だけで拾う | 28.5% |
| 業種を無視して店名でチェーン照合 | **66.7%** |

コンビニは店内調理があるため **`① 飲食店営業` で届け出ている**のが普通で、
業種コードで拾うと3分の2が消える。

`⑪ 百貨店、総合スーパー` も受け皿区分で、座標あり25,031件の100m以内にある
現行マスタの最寄り店舗の業態は **supermarket 49.9% / drugstore 34.1% /
convenience 5.8% / fresh_food 1.7% / 該当なし 8.4%**。
（これは `permit_excluded_sql()` が ⑪ からドラッグ名を落としている理由そのもの。）

→ **店名によるチェーン判定を主、業種を従**にする。これが `build_jff_only_master.py`。

## 2. 作り方（`scripts/build_jff_only_master.py`）

1. 座標があり `geocoding_level >= 8`（町丁目代表点を落とす）の行だけ使う
2. 県・市・正規化名・住所で施設に畳み、**業種は `string_agg` で全部持つ**
   （業種で先に絞ると「飲食店営業でしか届け出ていないコンビニ」が落ちる）
3. 同名が 50m 以内にある行を畳む（`permit_gapfill.py` と同じ規則）
4. 判定順に cat を振る。**先に決まったものを後段で上書きしない**

| 順 | cat | 条件 |
|---|---|---|
| 1 | drugstore | `DRUGSTORE_CHAINS` / `DRUGSTORE_TOKENS` に一致し、調剤専業でない |
| 2 | convenience | マスタの convenience ブランド辞書に一致、または `⑩ コンビニエンスストア` |
| 3 | supermarket | マスタの supermarket ブランド辞書に一致 |
| 4 | supermarket | `⑪ 百貨店、総合スーパー` かつ `permit_excluded_sql()` に当たらない |
| 5 | fresh_food | `FRESH_TYPE_SQL` かつ `fresh_excluded_sql()` に当たらない |

ブランド辞書はマスタの `brand` 列から全国10件以上・4文字以上のものを採る
（convenience 20・supermarket 111・drugstore 48・fresh_food 1）。
**チェーンでない独立店は名前で突合できないので拾えない。** これは織り込み済みの限界。

生行数 969,245 → 施設 806,454 → 同名50m を畳んで 767,482 → **cat が付いたもの 97,762**。

## 3. 件数（現行マスタ比）

| cat | ATP⑪ マスタ | JFF単独 | 比 |
|---|---:|---:|---:|
| convenience | 59,826 | 25,911 | 43.3% |
| supermarket | 32,696 | 20,274 | 62.0% |
| drugstore | 19,659 | 17,998 | 91.6% |
| **fresh_food** | 10,068 | **33,579** | **333.5%** |
| 計 | 122,249 | 97,762 | 80.0% |

**fresh_food が3.3倍**なのは既知の問題（生鮮3業種はセンサスの2倍あり、課題は収集ではなく
フィルタリング。`検証_許可データ_生鮮3業種_補完効果.md`）。**この過大が JFF単独を
実力より良く見せている**点に注意する。それでも下の結果になる。

## 4. 47県・道路距離で測った結果

判定は [japan-food-access-analysis](https://github.com/shiwaku/japan-food-access-analysis) の
`04_road_distance.py`（道路距離 m）→ `02_validate_access_difficulty.py`。同じ土俵。

| 領域 | 指標 | ATP⑪ 122,249店 | JFF単独 97,762店 | |
|---|---|---:|---:|---|
| 地方部（密度<1,500） | **相関 r** | **0.2472** | **0.2144** | ✗ 悪化 |
| 地方部 | 圏外率（65歳以上） | 56.32% | 66.89% | ✗ 店舗を取りこぼす |
| 地方部 | スーパー圏外率 | 80.17% | 89.98% | ✗ |
| 地方部 | 比>1 | 21件 | 12件 | 判定材料にならない（下記） |
| 都市部（密度≥1,500） | 相関 r | 0.7309 | 0.6596 | ✗ 悪化 |
| 都市部 | 圏外率 | 18.63% | 34.03% | ✗ |
| 全国 | 相関 r | 0.3334 | 0.3172 | ✗ 悪化 |
| 全国 | 圏外率 | 42.65% | 54.98% | — |

**比>1 が 21→12件に減ったことを改善と読んではいけない。** 店舗を減らせば圏外率が上がり
比（農水省÷本推計）は機械的に小さくなる。比は「1を超えたら論理矛盾」という
必要条件のチェックであって、小さいほど良い指標ではない。
**判別力があるのは r のほうで、3領域すべてで下がっている。**

## 5. 県によっては現行マスタより多い

`検証_JFF単独レイヤ_都道府県別.csv`。圏外率の差（JFF単独 − ATP⑪、プラスが悪化）。

| 悪い側 | 店舗 ATP⑪ | 店舗 JFF | 圏外率差 | | 良い側 | 店舗 ATP⑪ | 店舗 JFF | 圏外率差 |
|---|---:|---:|---:|---|---|---:|---:|---:|
| 愛知県 | 6,785 | 2,625 | +28.4pt | | 富山県 | 1,102 | 1,508 | **−4.7pt** |
| 新潟県 | 2,173 | 527 | +27.2pt | | 高知県 | 712 | 1,092 | −4.4pt |
| 青森県 | 1,372 | 382 | +26.2pt | | 山梨県 | 962 | 1,302 | −4.2pt |
| 神奈川県 | 7,684 | 4,200 | +23.2pt | | 石川県 | 1,231 | 1,724 | −3.0pt |
| 埼玉県 | 6,001 | 3,330 | +22.7pt | | 愛媛県 | 1,356 | 2,145 | −2.1pt |

**JFF が勝つ5県では現行マスタに無い店を持っている。** ただし生鮮の3.3倍過大が効いている
可能性があるので、県単位の純増をそのまま投入する前に生鮮を分けて測ること。

**そして、この県ごとのばらつきこそが単独採用を否定する理由でもある。**
収録の厚みが県で数倍違うレイヤは、市区町村間の比較（このマスタの主用途）を壊す。
純増が偏った投入で指標が悪化するのは #46 で実測済み。

## 6. 判定

- **単独では店舗レイヤにならない。** 3領域すべてで r が下がる。
- **チェーン名分類は業種コードより確実に良い**（コンビニ 28.5%→66.7%）。
  許可データを今後さわるときは業種コードで cat を振らないこと。
- **県を選んだ補完には材料がある**（富山・高知・山梨・石川・愛媛）。ただし
  投入効果は必ず 47県・地方部で測る。生鮮は分けて測る。
- ライセンスは再配布可（CC BY / 政府標準利用規約）。**自前クロール38本が
  再配布不可である問題の代替にはならない**（網羅率が足りない）。

## 7. 再現

```bash
curl -sSL -o data/facilities-all.csv https://food.japan-facilities.com/api/facilities-all.csv
python scripts/build_jff_only_master.py          # → data/food_store_jff_only.parquet

cd ../japan-food-access-analysis
cp ../japan-food-store-master/data/food_store_jff_only.parquet input/
FOOD_STORES=input/food_store_jff_only.parquet OUT_ROAD=data/mesh_road_dist_jffonly.parquet \
    python scripts/04_road_distance.py
ROAD_DIST=data/mesh_road_dist_jffonly.parquet OUT_SUFFIX=_JFF単独_47県 WRITE_MESH=0 \
    python scripts/02_validate_access_difficulty.py <47県>
```
