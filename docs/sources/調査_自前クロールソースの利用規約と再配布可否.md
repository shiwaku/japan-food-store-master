# 調査：自前クロールソース（ATP spider 24本）の利用規約と再配布可否

> 目的: `data/atp/*.geojson` を作っている自前クロール 24 チェーンについて、
> ①クロール行為が技術的に拒否されていないか（robots.txt）②各社規約が何を禁じているか
> ③成果物を再配布（All the Places 上流へ CC-0 で提供）できるか、を1枚に整理する。
> 既存の [調査_食料品店マスターのライセンス](../master/調査_食料品店マスターのライセンス.md) は
> Overture / OSM / 政府統計だけを扱っており、自前クロール分が抜けていた。その穴を埋める。
> 調査日: 2026-08-14（robots.txt と規約本文を実際に取得して確認）
>
> ⚠️ 技術的整理であり法的助言ではない。公開・商用化の前に原文と必要なら法務確認を。

## 結論（要約）

1. **クロール行為そのものを禁じているチェーンは、24社中ゼロ**。規約に
   「クローリング」「スクレイピング」「ロボット」「自動取得」に相当する語を置いている社は
   一つも無く、robots.txt でこちらのアクセス経路を塞いでいる社も無い。
2. **一方、再配布はほぼ全社が禁じている**。表現は各社ばらつくが、大半が
   「著作権法の私的使用の範囲を超える複製・頒布・販売はできない」型の条項を持つ。
   **CC-0 で公開する All the Places への提供は、この条項と正面からぶつかる**。
3. ただし **All the Places 上流には既に 15 本が取り込まれ、CC-0 で公開されている**（5章）。
   店舗の所在という事実に著作権は及ばないという立場に、プロジェクトとして立っている。
   **これは判例ではなく、上流プロジェクトの運用方針**。規約はそれとは別に**契約上の制約**として
   効くので、両者は矛盾せず併存する（1章）。
4. 本プロジェクトの用途（**ローカルでの分析・アクセス困難地域の推計**、生データを再配布しない）は
   各社が言う「私的使用」の側に収まる。**24 本すべて、現在の使い方は継続してよい**。
5. **新規に上流 PR を出すかは chain ごとに判断が要る**。特に危ないのは
   ポプラ（Google マイマップ経由）とイオン（規約に明記）の2本。

## 1. なぜ取得は問題にならず、再配布だけが問題になるのか

以降の表を読む前に、効いている法体系を分けておく。**取得と再配布は別の理屈で判断される**ので、
「事実だから著作権は及ばない」は再配布への反論にならない。

### レイヤー1: 著作権法（法定の権利・誰に対しても効く）

保護されるのは「思想又は感情を**創作的に表現**したもの」（著作権法2条1項1号）。
「ウエルシア○○店、住所△△、緯度35.xxx」は事実の記述であって創作的表現ではないので、
著作物にならない。ただし留保が3つある。

- **データベースの著作物**（12条の2）は別枠で、「情報の**選択又は体系的な構成**によって創作性を
  有するもの」は保護される。ただし保護対象は選択・構成であって中身の個々のデータではなく、
  かつ「全店舗を網羅的に並べる」のは選択に創作性が無いと評価されやすい。網羅は選択の対極。
- **日本には EU 型の sui generis データベース権が無い**。EU のデータベース指令は創作性が無くても
  「実質的な投資」があればデータの抽出自体を禁じられるが、日本にその規定はない。
  「金をかけて集めたデータだから」だけでは保護されない。
- **著作権法30条の4**（2018年改正）は、情報解析の用に供する場合の複製を許している。
  本プロジェクトの用途（食料品アクセス困難地域の推計）はここに素直に乗る。
  ただしこの条文が許すのは**解析のための複製**であって、**再配布（公衆送信）ではない**。

### レイヤー2: 利用規約（契約・当事者間だけで効く）

サイト利用規約は契約なので**相対効**しか持たない。ここが著作権との決定的な違いで、
次の非対称が生じる。

- 規約を読んでクロールした側は、拘束されるなら再配布しない義務を負う
- 一方 **CC-0 で公開されたものを使う第三者は、その規約の当事者ではない**ので何の義務も負わない

つまり「**著作権法上は適法だが契約上は違反**」が普通に成立する。これが結論3で言う「併存」。
効果も違い、契約違反は債務不履行（損害賠償・差止・アカウント停止）どまりで刑事罰は無い。
なお同意ボタンを伴わない「サイトに書いてあるだけ」の規約（ブラウズラップ）の拘束力は
日本でも争いがあり、一般には同意の外形が無いと契約成立を認めにくいとされる。
**無視してよいという意味ではなく、争点が残るという意味**。

### レイヤー3: この2つに乗らない別口

- **不法行為（民法709条）** — 著作物性が否定されても不法行為で救済された例がある
  （翼システム事件・東京地判 H13.5.25、自動車整備業向けデータベースのデッドコピー）。
  「著作権が及ばない＝何をしてもよい」ではない、という留保として効く。
- **業務妨害** — 過度なリクエストでサーバに負荷をかけた場合（岡崎市立中央図書館事件）。
  規約とも著作権とも無関係な**アクセスの作法**の問題。ATP の spider は download delay を
  入れているので現状は問題にならない。
- **不正アクセス禁止法** — 認証の突破が要件なので、公開ページを取る限り該当しない。
  WAF が UA で弾くのを Referer/Origin で通すのは認証の突破ではない（2章の注意点を参照）。

### 帰結

**リスクは取得側ではなく再配布側に集中している。** しかも再配布リスクは著作権ではなく
**契約**から来ているので、上流 ATP の「事実に著作権は及ばない」という立場は、
規約リスクへの反論にはなっていない。両方が別々に生きている。

## 2. robots.txt（クロールの技術的可否）

spider が実際に叩くホストの robots.txt を取得した結果。**該当パスを塞いでいる社は無い。**

### ⚠️ 403 を返す3ホストについて正直に書いておく

この3ホストは既定の UA を弾く。spider 側は**ブラウザが送るのと同じ `Referer` / `Origin`
ヘッダを付けて**通している（`matsukiyo_jp` は Referer、`seven_eleven_jp` と
`daily_yamazaki_jp` は Origin）。これは偽の身元を名乗っているのではなく、
**同じ画面をブラウザで開いたときと同じリクエストを出している**という位置づけ。
ただし「アクセス制限を回避した」と読まれる余地は残るので、上流 PR に出す場合は
このヘッダが必要な理由を spider のコメントに明記しておくこと（現状の3本は明記済み）。

## 4. 店舗検索の裏側にいる事業者（チェーンの規約より重いことがある）

店舗検索は自社実装より**外部の店舗検索パッケージ**であることが多い。データの出所が
チェーンでない場合、チェーンの規約だけ見ても足りない。

| プラットフォーム | 使っているチェーン | 注意点 |
|---|---|---|
| **ゼンリンデータコム Area Marker** | ローソン・セブン-イレブン・デイリーヤマザキ | `e-map.ne.jp/p/lawson/` は `areamarker.com/lawson/top` へリダイレクトする。同社の製品ページは**ゼンリン地図の許諾（許諾番号 Z20LE第1591号）**を明示。地図は許諾物だが、**店舗の緯度経度がゼンリン由来かは不明**。上流に出すなら一番確認が要る系統 |
| **NAVITIME 系（共通 robots.txt）** | イオン北海道・NewDays・成城石井・ウエルシア | robots.txt は全面許可。`proxy2/shop/list` という共通 API 形状 |

## 5. All the Places 上流との関係

24 本のうち **15 本は既に上流 master にあり、CC-0 で公開されている**。上流に入っている
＝「店舗の所在は事実であり公開できる」という立場に、プロジェクトとして立っているということ。
**判例が出ているわけではなく、上流の運用方針**である点に注意。しかもこれは1章のレイヤー1
（著作権）の話でしかなく、レイヤー2（規約＝契約）のリスクへの反論にはなっていない。
契約は当事者間にしか効かないので、**リスクを負うのは PR を出す側**（＝規約を読んでクロールした
こちら）であって、CC-0 で公開されたものを使う第三者ではない。

| 状態 | 本数 | spider |
|---|---|---|
| **上流 master にある** | 15 | `aeon_hokkaido_jp` `beisia_jp` `costco_jp` `familymart_jp` `heiwado_jp` `itoyokado_jp` `lawson_jp` `life_jp` `matsukiyo_jp` `ministop_jp` `seijoishii_jp` `seims_jp` `tomods_jp` `tsuruhadrug` `valor_jp` |
| **こちらで書いて commit 済み・未 push** | 3 | `sugi_jp` `trial_jp` `welcia_jp`（ブランチ `feature/welcia-jp`） |
| **こちらで書いてローカルのみ** | 6 | `aeon_jp` `daily_yamazaki_jp` `newdays_jp` `poplar_jp` `seicomart_jp` `seven_eleven_jp`（各 `feature/*-jp` ブランチ） |

### 上流 PR の推奨

| spider | 推奨 | 理由 |
|---|---|---|
| `sugi_jp` `trial_jp` `welcia_jp` | **出してよい** | 同業（ツルハ・マツキヨ・セイムス・バロー）が既に上流にあり、規約の書きぶりも同水準。追加のリスク要因が無い |
| `seicomart_jp` `newdays_jp` | **出してよい** | 規約は他社と同水準か、そもそも規約ページが無い |
| `daily_yamazaki_jp` `seven_eleven_jp` | **出せるが要注記** | Area Marker（ゼンリンデータコム）系。Origin ヘッダが必要な理由を spider に明記した上で |
| `poplar_jp` | **出さない方がよい** | 実体が Google マイマップの KML。Google の規約が別途かかる |
| `aeon_jp` | **出さない**（2026-08-11 決定済み） | 規約が私的使用を超える複製・頒布を明示的に禁止。ローカル私的利用のみで維持する |

## 7. まとめ：使い方別の可否

| 使い方 | 著作権法 | 規約（契約） | 結論 |
|---|---|---|---|
| クロールして手元に置く | 30条の4で適法。そもそも事実に著作権が及ばない | 自動取得を禁じる条項は24社ともゼロ | **可** |
| 手元で分析し、**集計結果や推計値**を公開する | 事実の集計であり著作物の複製ではない | 「複製・頒布」に当たらない | **可** |
| **生の店舗一覧をそのまま再配布**する | 侵害になりにくいが、不法行為構成の余地は残る | **大半の社の条項と正面から衝突** | **原則不可** |
| All the Places 上流へ PR（CC-0 で公開） | 同上 | 同上。ポプラは Google、イオンは明文で不可 | **chain ごとに判断**（5章） |

**リスクは取得側ではなく再配布側に集中している**、というのがこの表の要点。しかもその
リスクは著作権ではなく契約から来ている（1章）。
