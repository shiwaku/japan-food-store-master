## 結論

農水省の定義は **①店舗の定義**（生鮮食料品販売店舗／食料品スーパー・コンビニ等／ドラッグストア）と
**②操作化**（500mメッシュ単位の店舗存否・二値）の2階建て。両方に照らすと:

| 観点 | 判定 | 根拠 |
|---|---|---|
| ① 業態の網羅（コンビニ・ドラッグストア） | **満たす** | ATP 単独で実数統計比 convenience 100.9% / drugstore 110.2% |
| ① 業態の網羅（スーパー） | **半分** | ATP 単独 46.6%。地方チェーン・生協が未取得 |
| ① 業態の網羅（**生鮮食料品販売店舗**） | **満たさない** | fresh_food は 87,499件中 **1件**。定義の第1要素が空 |
| ② 500mメッシュ指標での整合 | **崩さない** | 3県88市区町村すべてで 比 農水省÷変種A ≤ 1（max 0.768→0.878） |
| ② 位置精度が500mメッシュに耐えるか | **6チェーンは不可** | 経度が系統的に約200m西へずれる（GSI 実測で確定）。952店 |
| 件数としての健全性 | **要精査** | 投入後 convenience 113.2% / supermarket 148.2% と実数超過 |
| 公開マスターへの投入可否 | **6割は不可** | 純増 23,607 のうち 13,968 は再配布禁止の自前クロール由来（§7） |

**総合**: 現行 ATP は「農水省の操作化を壊さずにメッシュの穴を埋める」データとしては有効で、
3県で 500m圏外の65歳以上人口を **−32,848人（62.2% → 59.3%）** 動かす。ただし
**投入前に (a) 座標バグ6チェーン、(b) 併設調剤の二重計上、(c) ブランド表記ゆれによる重複、の3点の修正が要る**。
さらに効果の6割は再配布できない自前クロール由来で、**公開マスターに入れられるのは ATP 公式ラン分（CC-0）だけ**（§7）。
生鮮は ATP では埋まらないので、[調査_freshfood補完ソース.md](調査_freshfood補完ソース.md) の路線と併走させる。

## 1. 農水省の店舗定義と ATP の対応

農水省2020年推計の店舗レイヤは「生鮮食料品販売店舗、食料品スーパー・コンビニ等 ＋ ドラッグストア
（日本スーパー名鑑、**電話帳データ**等）」。4要素のうち ATP が満たすのは2.5要素:

| 農水省の要素 | 対応する cat | ATP | 実数統計 | ATP単独率 |
|---|---|---:|---:|---:|
| 食料品スーパー | supermarket | 10,438 | 22,378（センサス581） | **46.6%** |
| コンビニ | convenience | 57,052 | 56,352（商業動態） | **100.9%** |
| ドラッグストア | drugstore | 19,434 | 17,622（商業動態） | **110.2%** |
| 生鮮食料品販売店舗 | fresh_food | **1** | 33,960（センサス582/583/584） | **0.0%** |

- コンビニはセブン-イレブン（21,850）の自前クロールが入ったことで、**ATP だけで実数と並んだ**。
  前回検証の 53.8%（ファミマ＋ローソンのみ）から倍増している。
- ドラッグストアは **ATP 単独で実数超過**（110.2%）。マスター現行は 42.5% なので、
  この業態は ATP がマスターより明確に上。ただし超過分の一部は §5 の二重計上。
- fresh_food の 1 件は maruetsu_jp に紛れた「魚悦 糀谷店（鮮魚専門店）」。実質ゼロで、
  **チェーンスクレイピングでは農水省定義の生鮮レイヤは原理的に埋まらない**という前回の結論は不変。

## 2. 抽出規則が何を採り、何を落としたか

`scripts/fetch_alltheplaces_jp.py` の分類規則（OSM 互換タグ → 4カテゴリ）を通した結果:

| | 件数 |
|---|---:|
| 採用 | **86,925** |
| 不採用 | 574 |
| 生データ計 | 87,499 |

不採用の内訳（**すべて農水省定義に照らして妥当**）:

| 理由 | 件数 | 中身 |
|---|---:|---|
| 調剤専業（brand 無しの `amenity=pharmacy`） | 259 | sundrug_jp 226（「◯◯薬局」＝調剤専門店舗）ほか |
| 調剤専業（名称判定） | 96 | 「ライフォート ◯◯薬局」等。`food_store_rules.py` の共有ルール |
| 座標が無い | 84 | genky 65 / lopia 14 ほか。ジオコーディング未達 |
| 食料品店でないタグ | 135 | `cosmetics` 59（化粧品専門店）/ `kiosk` 50（駅売店）/ `ice_cream` 7 / `department_store` 5 ほか |

- **`kiosk` 50 件（NewDays KIOSK）を落としている**のは、商業動態統計のコンビニ定義（売場30㎡以上・
  セルフサービス）に照らせば妥当。ただし駅売店を「食料品が買える場所」と数える立場なら取りこぼし。
- 座標が無い 84 件は `scripts/geocode_atp_geojson.py` の GSI ジオコーディングの残り（既に 812 件は補完済み）。

## 4. 農水省の操作化（500mメッシュ二値）で見た効果 ← 本命

件数の純増と、農水省の指標に効く量は**一致しない**。純増 23,607 点を 500mメッシュに落とすと:

| | 件数 |
|---|---:|
| 純増点 | 23,607 |
| **うち既に店舗があるメッシュに落ちる（指標に効かない）** | **15,997（67.8%）** |
| 新規メッシュを生む点 | 7,610（32.2%） |
| 新たに埋まる500mメッシュ | **6,821**（マスター現行 54,928 → +12.4%） |

3県88市区町村（宮城・島根・高知、対象県内の純増はわずか **681点**）での前後比較:

| 指標 | 投入前 | 投入後 |
|---|---:|---:|
| 変種A 500m圏外人口（65歳以上） | 685,951（62.2%） | **653,103（59.3%）** |
| 変種C 実距離500m 圏外人口 | 453,617（41.2%） | 430,133（39.0%） |
| 比 農水省÷変種A | 0.420 | **0.441** |
| 比の中央値 / sd / max | 0.364 / 0.108 / 0.768 | 0.372 / 0.118 / **0.878** |
| 全市区町村で 比 ≤ 1 | 満たす | **満たす** |

- **穴が 32,848人分（−2.9pt）埋まる**。前回（公式14 spider）の −15,744人（−1.4pt）の倍。
  681点しか増えていない県で 3万人分動くのは、地方部では1店舗が数百人を救うため。
- 比が 0.420 → 0.441 と 1 に近づき、論理的不整合（比 > 1）は出ない。
  **農水省の操作化を壊さない**＝定義適合の面では合格。
- ただし **比のばらつきは 0.108 → 0.118 と広がった**。穴が均等に埋まったのではなく、
  仙台市 0.678→0.760、多賀城市 0.768→**0.878** と**都市部が偏って埋まっている**。
  ATP がチェーン専用ソースである以上、これは構造的な偏り。

カテゴリ感度（500m圏外の65歳以上人口・対象県計）:

| 店舗集合 | 投入前 | 投入後 |
|---|---:|---:|
| S1 supermarket のみ | 916,991（83.2%） | 910,604（82.6%） |
| S2 ＋convenience | 734,638（66.7%） | 705,803（64.1%） |
| S3 ＋drugstore | 722,080（65.5%） | 683,433（62.0%） |
| S4 全カテゴリ | 685,951（62.2%） | 653,103（59.3%） |

convenience の寄与が 182,353 → 204,801 人、drugstore が 12,558 → 22,370 人へ増える。
**CLAUDE.md の優先順（convenience ＞ fresh_food ＞ drugstore）と整合**する動き方。

## 5. 投入前に直すべき3点

### (a) 6チェーンの座標が系統的に約200m西へずれている（952店）

同ブランドの既存店との差分の中央値を取ると、緯度は合っているのに経度だけずれる spider がある。
**マスター（Overture）と OSM は互いに一致し、ATP だけがずれている**ので ATP 側の誤り。
国土地理院ジオコーダで住所から実測して確定させた（万代6店を抜き取り）:

| spider | 店舗数 | ATP−マスター 経度 | ATP−OSM 経度 | GSI 実測（ATP / マスター） |
|---|---:|---:|---:|---|
| mandai_jp | 170 | −230m | −229m | ATP 191〜278m ずれ / マスター 18〜55m |
| york_benimaru_jp | 251 | −193m | −197m | — |
| harashin_narus_jp | 81 | −196m | −197m | — |
| izumi_jp | 122 | −198m | −199m | — |
| belc_jp | 147 | −192m | −196m | — |
| ok_store_jp | 181 | −158m | −166m | — |

**500mメッシュ判定では 200m のずれは致命的**（メッシュ1辺の40%）。実際、同ブランドで対応が取れた
ペアの「同一メッシュ率」は全体 86.2%（中央値 8m・63,199ペア）に対し、この6チェーンは 59〜72%。
6本とも 2026-08-25 の自前クロールなので、**クローラの座標取得系を1か所直せば全部直る**見込み。

さらに **yaoko_jp は 204件中 146件が「別店舗なのに同一座標」**（GSI ジオコーディングが同じ点へ潰れた）。
投入対象から外すか、住所を細かくして取り直すこと。

### (b) 併設調剤が別レコードになっている（drugstore の二重計上）

同一 spider・50m以内のペアをタグの組で数えると `chemist`×`pharmacy` が 560 組。
うち採用側に残るのは **matsukiyo_jp 216 / cawachi_jp 159** など約 390 組で、
「カワチ薬品◯◯店（chemist）」と「◯◯調剤（pharmacy）」が同一店舗を2回数えている。
drugstore の 110.2% にはこの分が乗っている。

### (c) ブランド表記ゆれで重複が「純増」に化ける

**マスターは「セブンイレブン」、ATP は「セブン-イレブン」**（ハイフンの有無）。
現行の突合ルール（同ブランド500m）はこの表記ゆれを吸収できず、
**seven_eleven_jp の純増 3,415 件のうち 1,570 件（46.0%）は、正規化すれば 500m 以内に既存店がある**。
ministop_jp 13.0% / lawson_jp 6.3% も同様。純増全体では 1,713 件（7.3%）が重複。
突合前に `-`／`‐`／`－`／空白を落として正規化すること（前回検証で name→brand の比較に直したのと同じ種類の罠）。

## 6. 副産物: マスターと OSM 側で見つかった測地系ズレ

ATP を第三者データとして当てたことで、**既存データ側のバグが2件見つかった**。

- **マスターのデイリーヤマザキ 943件が旧日本測地系のまま**（ATP・OSM の双方に対して
  北へ+358m・西へ−264m ＝ 測地系変換分そのもの）。ATP と OSM は互いに 1m で一致するので、
  ずれているのは Overture 由来のマスター側。**測地系を補正すると 943 件中 824 件（87%）が別メッシュへ移る**
  ＝ 現状は農水省指標を直接誤らせている。ATP を投入すれば結果的に正しい位置の点が入る。
- **OSM のローソン 11,369件も約440mずれている**（ATP から100m以内にあるのは 3.3%、500m以内なら 93.4%）。
  他ブランドは 80〜93% が100m以内に一致するので、ローソンだけの問題。
  マスターのローソンは全件 Overture 由来なのでマスターは無傷だが、
  **viewer が配信する `osm_food.pmtiles` はこのズレを含んでいる**。

## 7. ライセンス: 効果の 59% は公開マスターに入れられない

52チェーンの出自は **ATP 公式ラン 14本（CC-0）** と **自前クロール 38本** に割れる。
自前クロール分は [調査_自前クロールソースの利用規約と再配布可否.md](調査_自前クロールソースの利用規約と再配布可否.md)
（PR #23・main へは未マージ）の結論どおり、**クロール自体は robots.txt・規約とも禁じられていないが、再配布はほぼ全社が禁止**。

| 区分 | 純増 | 新規メッシュを生む点 | 公開マスターへの投入 |
|---|---:|---:|---|
| ATP 公式ラン 14本 | 9,639 | 3,248 | **可**（CC-0） |
| 自前クロール 38本 | 13,968 | 4,362 | **不可**（各社規約で再配布禁止） |

- §4 の「−32,848人」の効果のうち、**公開できるデータで再現できるのは4割弱**。
  残りはローカルでの推計・検証にとどめ、`data/food_store_master.csv` には混ぜられない。
- セブン-イレブン（21,850）・イオン・ウエルシア等の主力は自前クロール側なので、
  **§1 の「コンビニ 100.9%」「ドラッグストア 110.2%」は公開マスターの到達点ではない**。
- 公開マスターとしての底上げを狙うなら、自前クロールで見つけた店舗を **OSM へ反映して回収する**
  （ODbL 継承は増えるがライセンス上は正規のルート）か、ATP 上流へ spider を提供して
  CC-0 として戻す道になる。ただし ATP 上流はサイト規約より運用方針を優先する立場で、
  ポプラ（Google マイマップ経由）とイオン（規約に明記）は出せない。

## 8. 次の一手

1. 上記 (a)(b)(c) を直す。特に (a) は6チェーン共通のクローラ修正で片付く。
2. 直したうえで **convenience の偽陽性精査**（投入後 113.2% を実数に戻す作業）。順序は前回結論のとおり
   ①マスター側の偽陽性を引く → ②ATP で足す。
3. supermarket は ATP 単独 46.6% で、生協・ユニー系・東急ストア等の未取得チェーンが残る。
   ただし1チェーン100〜300店の裾なので、費用対効果は逓減。
4. **fresh_food は ATP の対象外**。[調査_freshfood補完ソース.md](調査_freshfood補完ソース.md) の
   食品営業許可・届出（生鮮3業種 95,065行）の条件付き昇格を並行して進める。
5. マスターのデイリーヤマザキの測地系ズレは、ATP 投入の有無に関わらず単独で直す価値がある。
6. 公開マスターと、ローカル推計専用レイヤ（自前クロール分）を**分離して持つ**設計を決める。
   これは [調査_freshfood補完ソース.md](調査_freshfood補完ソース.md) の候補2（タウンページ系は再配布不可）と同じ論点で、
   同じ仕組みで扱える。
