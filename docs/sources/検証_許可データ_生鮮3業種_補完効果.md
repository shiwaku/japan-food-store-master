# 検証: 食品営業許可・届出の生鮮3業種で fresh_food の穴を埋められるか

CLAUDE.md「次の一手」2番（fresh_food の補完）の実測記録（2026-08-27）。**マスターは書き換えていない**。

再現: `python3 scripts/extract_permit_fresh_food.py`
（`FOOD_MASTER` / `INCLUDE_PACKAGED` / `MIN_LEVEL` / `OUT_PARQUET` / `OUT_CSV` / `RADIUS_M` で差し替え可）。
路線の選定理由は [調査_freshfood補完ソース.md](調査_freshfood補完ソース.md)
（農水省本家の生鮮レイヤーは電話帳データ製だが有償・再配布不可。許可・届出データが唯一、
無償・再配布可で公開マスターと両立する候補）。

## 0. 結論 — 効く。**ATP 基準マスターには投入済み**（§6）

`r` は検証器が出す **市区町村別の「圏外率_変種A」と「農水省_困難人口割合」の相関**（n=88）。

| 構成 | 店舗数 | 3県の500m圏外率 | 比 農水省÷変種A | 比の max | 相関 r |
|---|---:|---:|---:|---:|---:|
| 現行マスター | 102,984 | 62.2% | 0.420 | 0.768 | 0.448 |
| ＋許可⑪ のみ（4,191件） | 107,175 | 61.4% | 0.426 | 0.768 | **0.445** |
| ＋生鮮3業種（17,880件） | 120,864 | **60.1%** | 0.434 | 0.768 | **0.460** |
| ＋生鮮3業種＋許可⑪ | 125,055 | **59.3%**※ | 0.440 | 0.768 | **0.462** |
| ATP基準マスター | 119,092 | 59.8% | 0.437 | 0.793 | 0.448 |
| ATP基準＋許可⑪ のみ（3,157件） | 122,249 | 59.2% | 0.442 | 0.793 | 0.445 |
| **ATP基準＋生鮮（17,243件）＋許可⑪** ＝**投入した版** | **139,492** | **57.3%** | 0.456 | 0.793 | **0.462** |

※ 生鮮＋⑪ の 59.3% は `MIN_LEVEL=3`（生鮮 21,511件）で測った値。level 3 を落としても
指標は動かない（§3）ので、そのまま読んでよい。

- 生鮮3業種の純増は **17,880件**（現行マスター基準／ATP基準では 17,243件）。それで **−2.1pt**。
- **比 > 1 の市区町村は 0 / 88 のまま**（max 0.768）＝メッシュ指標の操作化は壊れない。
- **農水省公表値との相関が上がる**（r 0.448 → 0.460、⑪ と併せて 0.462）。
  件数を足すと圏外率は必ず下がるので、下がったこと自体は判定材料にならない。
  **相関が上がることが「穴を埋めている」ことの証拠**になる。
- **⑪ 総合スーパー単独では相関がわずかに下がる**（0.448 → 0.445）。⑪ の純増は都市部に多く
  （静岡・福岡・東京に多い）、困難人口が多い地方の穴に効いていないため。
  生鮮は逆に地方に厚く（高知372）、**穴を埋める順序としては生鮮が先**。
- fresh_food は CLAUDE.md の感度分析で「不足23,890店・伸びしろ最大」と見積まれていた枠。
  投入後のカテゴリ感度でも **fresh_food の寄与が −4.7pt** と最大になった（補完前は −3.3pt）。

## 1. 対象業種と規模

| 業種（部分一致） | 生行数 |
|---|---:|
| 食肉販売業（包装済み含む） | 38,666 |
| 魚介類販売業（包装済み含む） | 37,907 |
| 野菜果物販売業 | 15,501 |
| **計** | **92,074** |

抽出条件は `food_store_rules.py` の `FRESH_TYPE_SQL`。
**製造業・処理業・競り売り（卸売市場）・小分け業は入れない**
（`食肉処理業` 4,261 / `食肉製品製造業` 1,451 / 競り売り・せり売 623 ほか）。

既定（未包装＝許可のみ）で拾う生行数は **71,091**。ここから施設単位に畳んで 58,493 件、
同名 50m の重複を畳んで 51,169 件。

既定では**「包装済みのみ」の届出を落とす**（`INCLUDE_PACKAGED=1` で含められる）。
包装済みは届出業種で捕捉が薄く、スーパーの売場が中心。含めると純増は約2割増えるが、
センサス比が 105% を超えて業態の純度が落ちる。

## 2. 課題は収集ではなくフィルタリング

施設単位に畳むと 58,493 件（未包装のみ）で、**センサス 582/583/584 計 33,960 の約1.7倍**ある。
名称でバケット分けした実測（71,254件・包装済み込み）:

| バケット | 件数 | 比率 |
|---|---:|---:|
| スーパー・GMS | 5,912 | 8.3% |
| コンビニ | 3,484 | 4.9% |
| 卸・市場・仲卸 | 1,047 | 1.5% |
| 加工・製造 | 794 | 1.1% |
| 事業所内・施設 | 487 | 0.7% |
| 移動販売・露店 | 397 | 0.6% |
| その他 | 58,816 | 82.5% |

「その他」にも飲食店とスーパーが残る（サンプル目視で確認）。3段のフィルタをかけた:

### ① 名称フィルタ（`fresh_excluded_sql()`）

**飲食店を落とすのが最重要**。焼肉・寿司・ステーキ店が食肉／魚介類販売業の許可を取っているので、
放置すると全国に偽の食料品店が湧いて 500m メッシュ指標が過小に出る（比が1を超える方向）。
ほかに 卸・市場・仲卸／加工場・工場／移動販売・露店・無人販売／事業所内・センター・事務所／
ドラッグストア（別カテゴリで補完済み）を落とす。この段で **5,447 件**を除外。
さらに座標精度（`MIN_LEVEL=8`、§3）で 8,423 件を落として候補 37,205 件になる。

> ⚠️ **「センター」を一括で落としてはいけない**。JA の「○○生活センター」やフードセンター・
> ショッピングセンターは**店舗**（⑪ 総合スーパーの有力候補でもある）。
> 施設側の複合語（教育センター・研修センター・給食センター等）だけを列挙する。

### ② チェーン売場フィルタ（データ駆動）

スーパー／コンビニの鮮魚・精肉コーナーの届出（「イオン福岡伊都店　水産作業室」
「ベルクス川口朝日店（鮮魚）」）を落とす。**チェーン名は列挙し切れない**ので、
「マスターに同じ先頭3文字で始まる店が全国10件以上ある」名前をチェーンと判定する。

> ⚠️ **接頭辞は短くしないと効かない**。ブランドキー（先頭5文字）で突合すると、
> 「ローソン」は正規化で長音が落ちて3文字（ロソン）になり、キーに店名が食い込んで
> 店ごとに変わるため**一件も当たらない**（コンビニの売場が丸ごと漏れる）。
> 実測: 先頭3文字・10件以上で 4,953件、先頭4文字だと 1,894件しか当たらない。

この段で **8,186 件**を除外（37,205 → 29,019）。落ちたものはスーパー／コンビニの穴であって
**fresh_food の仕事ではない**（issue #26 / #33 の系統で扱う）。

### ③ マスターとの突合

100m 一致＋同ブランド500m 一致。既存店の売場・重複がここで落ちる。

| 半径 | 距離のみで一致 | ＋同ブランド500m | 純増 | 純増率 |
|---:|---:|---:|---:|---:|
| 50m | 7,122 | 7,511 | 21,508 | 74.1% |
| **100m** | 10,966 | 11,139 | **17,880** | 61.6% |
| 200m | 16,327 | 16,393 | 12,626 | 43.5% |
| 300m | 19,542 | 19,560 | 9,459 | 32.6% |
| 500m | 22,723 | 22,723 | 6,296 | 21.7% |

## 3. 座標精度

同ブランドの既存マスター店舗までの距離（既定 `MIN_LEVEL=8` で、対応が取れた 2,174件）:
中央値 **15m** / p75 44m / p90 **126m**。

⑪ 総合スーパー（中央値18m・p90 134m）と同程度。個人商店はブランド突合が効かないので
標本が候補の7%しかなく、この分布はチェーン系に偏っている点に注意。
`MIN_LEVEL=3` の足切りは効いていない（level 1・2 の行がそもそも無い）。
精度レベル別の純増率は 元座標 63.0%（23,989件）/ level 3 が **70.4%**（5,161件）/
level 8 が 55.1%（5,030件）で、**level 3（町丁目レベル）の純増率が高い＝座標が粗い分だけ
純増に化けている疑いがある**。

### `MIN_LEVEL=8` を既定にした（測定した）

level 3（町丁目レベル）を落とすと純増は 21,511 → **17,880**（−3,631。ATP基準では 20,959 → 17,243）
に減るが、**メッシュ指標は 1mm も動かない**:

| | 純増 | 3県圏外率 | 比 | 相関 r | 座標精度（中央値 / p90） |
|---|---:|---:|---:|---:|---|
| `MIN_LEVEL=3` | 21,511 | 60.1% | 0.435 | 0.460 | 20m / 220m |
| **`MIN_LEVEL=8`（既定）** | 17,880※ | 60.1% | 0.434 | 0.460 | **15m / 126m** |

※ 現行マスター基準。ATP 基準では 17,243。level 3 の候補は 8,423件（施設単位）落ちる。

**指標が同じで座標品質だけ上がる**＝ level 3 の点は指標に何も足していない（既にカバー済みの
メッシュに落ちているか、町丁目重心が誤ったメッシュを埋めているか）。保守的に落とす方を既定にした。

## 4. 「カバー率」では判定できない

県別は `検証_許可データ_生鮮3業種_都道府県別.csv`。全国では fresh_food が
29.7% → 82.3% になるが、**20/47 県でセンサスを超える**（岩手 166% / 長野 160% / 愛媛 155%）。

これは過大ではなく**分母のずれ**で、issue #33 の supermarket 137% と同じ構図:

- センサス 582/583/584 は「**主業が**精肉／鮮魚／青果の事業所」を数える。
- 許可・届出は「その場所で生鮮を売る許可を持つ施設」で、主業が米屋・酒屋・直売所・
  よろず商店でも入る。**母集団が定義上広い**。

農水省の店舗レイヤー（電話帳製の「生鮮食料品販売店舗」）が正しい分母だが、有償で手元に無い。
→ **判定はメッシュ検証（比≤1 と農水省との相関）で行う**。§0 の通り両方満たす。

沖縄の純増サンプル: まる嵩商店 / 石川ミート / なか村水産 / はるみ鮮魚 / 砂川かまぼこ店 /
大江ストアー / 西江上売店 — 沖縄の fresh_food カバー率は 19.5% で、実際に穴が大きい。

## 5. 残る限界

1. **廃業・閉店が落とせない**。届出行に `license_date` / `expire_date` が無い（⑪ と同じ）。
2. ~~level 3 の座標粗さ~~ → 測定して既定を `MIN_LEVEL=8` にした（§3）。
   落とした 4,268件は指標に何も足していなかった。
3. **カテゴリは fresh_food 一括**。魚介／食肉／野菜果物の内訳は候補 parquet に
   `business_type` を残していないので分からない（施設単位に畳む段で落としている）。
4. **飲食店フィルタは名称ベース**。屋号に業種語を持たない飲食店（「和の月」等）は残る。

## 6. 投入した（2026-08-27）

**ATP 基準マスター（推計用）に投入済み** → `data/food_store_master_atp_permit.parquet`（139,492件）。
生鮮 17,243 ＋ ⑪ 3,157 で、3県の500m圏外率 **57.3%** / 比 0.456（max 0.793）/ r **0.462**。
手順は [../master/設計_ATP基準マスター構築.md](../master/設計_ATP基準マスター構築.md)「許可データの投入」。

**公開マスター（Phase1）へはまだ入れていない。** ライセンス上の障害は無い（許可データは CC BY /
政府標準で再配布可）が、公開マスターは viewer の PMTiles と件数表（`viewer/src/layers.ts` の `COUNTS`）に
連動しており、投入するならタイル再生成まで含めて一度に行う必要がある。
