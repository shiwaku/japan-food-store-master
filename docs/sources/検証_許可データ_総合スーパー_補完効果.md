# 検証: 食品営業届出「⑪ 百貨店、総合スーパー」で supermarket の穴を埋められるか

issue #26 の実測記録（2026-08-27）。**マスターは書き換えていない**。採否の材料を出すのが目的。

再現: `python3 scripts/extract_permit_supermarkets.py`（`FOOD_MASTER` / `OUT_PARQUET` / `OUT_CSV` /
`RADIUS_M` で差し替え可）。入力は `data/facilities-all.csv`（`japan-facilities-address` の統合出力、
1,437,799 行）と現行マスター。

## 0. 結論

**採る価値はある。ただし効果は「件数の純増」より一桁小さい。**

| 指標 | 現行マスター | 許可⑪ 投入後 | ATP基準マスター | ATP基準＋許可⑪ |
|---|---:|---:|---:|---:|
| 店舗数 | 102,984 | +4,191 | 119,092 | +3,157 |
| 3県の500m圏外率（65歳以上） | 62.2% | **61.4%** | 59.8% | **59.2%** |
| 比 農水省÷変種A | 0.420 | 0.426 | 0.437 | 0.442 |
| 比 > 1 の市区町村 | 0 / 88 | **0 / 88** | 0 / 88 | **0 / 88** |

- 全国 4,191 件の純増に対し、検証3県（高知・島根・宮城）に落ちるのは 143 件。
  それで圏外率が **−0.8pt** 動く（ATP 基準では純増 3,157 件・−0.6pt）。
  ATP 基準への組み替え（+16,108件）の −2.4pt と比べると、**1店あたりの効き方はむしろ大きい**
  （周囲に何も無い場所の店を拾えているため）。
- メッシュ指標の整合（全市区町村で 比≤1）は**壊れない**。
- ライセンスは CC BY 4.0 / 政府標準利用規約で**再配布可**。ATP の自前クロール分と違い公開マスターに入れられる。

**投入の推奨**: ATP 基準マスター（推計用）には入れてよい。公開マスター（Phase1）への投入は
supermarket が既に広義で実数の 137% ある問題（issue #33）を整理してからにする。

## 1. 抽出条件（落とし穴つき）

### ⚠️ 区分番号「⑪」は衝突する

`business_type` に付く丸数字は**許可業種と届出業種で別体系**で、番号が重複する。

| business_type | 行数 | 体系 |
|---|---:|---|
| `⑪ 菓子製造業` | 37,032 | 許可業種 |
| `⑪ 百貨店、総合スーパー` | 25,189 | 届出業種 |

**番号だけで絞ると菓子製造業を巻き込む**。抽出は区分名まで含めた完全一致で行う。

### ⚠️ 届出行には日付列が無い ＝ 廃業の除外ができない

`⑪ 百貨店、総合スーパー` の 25,189 行は `license_date` / `expire_date` が**全件空**
（届出に許可の有効期限が無いため）。許可業種の行には日付があるが、届出には無い。

→ issue #26 のチェック項目「廃業行の除外（expire_date / 廃業年月日）」は
**このデータでは実行不可能**。閉店店舗が混じる方向の偽陽性が残る（Overture deduped と同じ弱点）。

## 2. 業態純度（issue #26 チェック項目1）

⑪ は**届出の受け皿区分**で、食品を売る大型小売がまとめて入る。施設単位に畳んだ 24,948 件の内訳:

| 除外グループ | ヒット | 増分 | 判断 |
|---|---:|---:|---|
| ドラッグストア | 8,598 | 8,598 | 農水省定義には含まれるが、ATP 基準で既に実数の 111.6% あり補完不要 |
| ホームセンター | 426 | 426 | センサス581 に入らない。マスター側も殆ど持っていない（コーナン2件・カインズ2件） |
| 家電・衣料・雑貨 | 20 | 19 | ドン・キホーテは**除外しない**（食品主力・マスターにも138件ある） |
| 移動販売（とくし丸・○号車） | 195 | 149 | 定点でないので500mメッシュに固定できない |
| 事業所内・施設（研究所・テレビ局・駅ビル等） | 189 | 136 | 一般客が使えない、または施設名で登録されている |
| **合計（重複除く）** | **9,328** | | |

判定リストは `scripts/food_store_rules.py` の `permit_excluded_sql()`（構築と検証で共有）。

上の内訳は畳む前の 24,948 件に対する数。スクリプトは同名 50m の重複を畳んだ 24,363 件に適用するので、除外は **9,213 件**、名称・座標の欠損を除いた**候補は 15,140 件**になる（事業部・営業所などの事務所名を落とす分を含む）。

ドラッグ名を落とした 16,366 件をキーワードで分類すると、上のどのグループにも当たらない
「その他」が **91.2%（14,924件）**。この「その他」からランダム120件を目視した結果、
実質スーパー・食料品店が大半で、混ざるのは除外リストで落ちる分（ホームセンター・移動販売・
事業所内売店）と、個人商店（「原田勲」「大門」「あさひや」など屋号だけの店）。
個人商店は農水省の食料品小売業に含まれるので**残す**。

拾えている層の例（ATP のチェーンクロールでは原理的に取れない）:
ラ・ムー / MEGAドン・キホーテUNY / Da*マルシェ歌志内（道北アークス） / 庄原農業協同組合 口和生活センター /
スーパー公正屋 / タウンプラザかねひで / ルミエール / かましん / アルク / SANPHAMVIET（ベトナム食材店）

## 3. 座標精度と突合（issue #26 チェック項目3）

「100m 以内に既存店が無い＝純増」は、**許可データの座標がずれていれば偽の純増になる**。
同ブランドの既存マスター店舗までの距離で座標精度を測った:

| | 値 |
|---|---:|
| 対応が取れた候補 | 7,265 件 |
| 中央値 | **17m** |
| p75 / p90 | 43m / 114m |
| 50m以内 / 100m以内 | 78.0%（5,667件）/ 88.5%（6,430件） |

**座標は良い**（元座標が 24,994/25,189 行で、ジオコーディング補完は 195 行だけ）。
100m 判定は妥当と判断できる。

突合は ATP 検証と同じ二段構え（`docs/sources/検証_AllThePlaces_網羅性と採用可否.md`）:
距離 100m の一致に加えて、**同ブランドが 500m 以内にあれば同一店**とみなす。

### ⚠️ ブランド突合は両方向見る

法人名が**名称の途中**に入る形がある（「イオンリテール株式会社イオン小松店（寿司）」）。
許可側の先頭5文字をマスター名に当てる片方向だけだと突合キーが「イオンリテル…」始まりになり、
マスターの「イオン小松店」に当たらず**偽の純増**になる。マスター側の先頭5文字を許可名に当てる
逆方向も併用して救う（`match_key_sql()`。法人語は先頭だけでなく**どこにあっても落とす**）。

### 半径の感度

| 半径 | 距離のみで一致 | ＋同ブランド500m | 純増 | 純増率 |
|---:|---:|---:|---:|---:|
| 50m | 8,561 | 9,803 | 5,337 | 35.3% |
| **100m** | 10,448 | 10,949 | **4,191** | 27.7% |
| 200m | 12,335 | 12,510 | 2,630 | 17.4% |
| 300m | 13,355 | 13,404 | 1,736 | 11.5% |
| 500m | 14,269 | 14,269 | 871 | 5.8% |

純増 4,191 のうち **3,320 件は「500m以内に別ブランドの店はあるが、同一店は無い」**。
同一ブランドの一致は 500m まで見て潰してあるので、この 3,315 件は座標ズレではなく
**隣に別の店がある店**（都市部で普通に起きる）。したがって 100m 判定の純増は妥当。

ただし農水省の指標は**同一500mメッシュ内の店舗存否**なので、
「500m以内に既存店がある純増」はメッシュ判定をほぼ動かさない。
**指標に効くのは 871 件前後が上限**という見立てになる（§0 の効果がこの規模で説明できる）。

## 4. 県別（issue #26 チェック項目2）

`検証_許可データ_総合スーパー_都道府県別.csv`。分母は既存検証と同じ実数統計（センサス581）。

⚠️ **候補の厚みが県で3〜6倍ばらつく**（許可データの既知の穴と整合する）:

| 都道府県 | ⑪候補 | 純増 | 実数統計(581) | 候補÷実数 |
|---|---:|---:|---:|---:|
| 新潟県 | 92 | 43 | 490 | **0.19** |
| 島根県 | 61 | 28 | 273 | 0.22 |
| 茨城県 | 288 | 72 | 510 | 0.56 |
| 宮崎県 | 210 | 108 | 315 | 0.67 |
| 静岡県 | 646 | 233 | 533 | **1.21** |
| 福岡県 | 730 | 192 | 653 | 1.12 |
| 全国 | 15,140 | 4,191 | 22,378 | 0.68 |

新潟・茨城・宮崎に穴があるという既知の傾向はそのまま出た。**穴の県は補完も薄い**ので、
この補完は県間の比較可能性をむしろ悪化させる方向に働く。県別の絶対値を使うときは注意。

なお supermarket の全国カバー率は 136.9% → 155.6% に上がるが、**この分母の取り方が誤っていた**。
issue #33 で分解した結果、マスターの supermarket は Overture `supermarket` 由来 18,487件（センサス
561+581 の 79.0%＝**不足**）と `grocery_store` 由来 12,151件（589系・分母が手元に無い）の合成だった。
→ `docs/master/検証_supermarket分解と分母の確定.md`。**⑪ の補完は「過剰な枠をさらに膨らませる」のではなく、
不足している枠を埋めている**。

**生鮮3業種は逆に地方へ厚く入り r が上がる**（0.448 → 0.460。

**投入の順序は生鮮が先**。

市区町村別は `検証_許可データ_総合スーパー_アクセス困難人口_市区町村別.csv`（現行マスター＋許可⑪）。

## 6. 残る限界

1. **廃業・閉店が落とせない**（§1）。届出データに日付列が無い。偽陽性は過剰計上の方向。
2. **県別の偏り**（§4）。許可データが薄い県は補完も薄い。
3. **⑪ は受け皿区分**なので、名称による業態フィルタが本体（§2）。新しい非食料品チェーンを
   見つけたら `permit_excluded_sql()` に足す。
4. **fresh_food には効かない**。⑪ は総合スーパーの区分で、生鮮3業種は別区分
   （`docs/sources/調査_freshfood補完ソース.md` の路線）。
